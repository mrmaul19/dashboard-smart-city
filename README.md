# Smart City Digital Twin — Jakarta

An interactive 3D digital twin of Jakarta that combines real OpenStreetMap
geometry with live weather and air-quality data from free, open public APIs.
Built as a command-centre style monitoring dashboard.

**No paid APIs, no map subscriptions, no VPS.** Deploys to Vercel's free tier.

## Getting started

```bash
npm install
cp .env.example .env.local   # optional until phase 4
npm run dev
```

Open http://localhost:3030.

| Script | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Production build (also runs the TypeScript check) |
| `npm run lint` | ESLint |
| `npm run data:city` | Regenerate the OpenStreetMap geometry snapshot |
| `npm run data:transit` | Regenerate the Transjakarta GTFS snapshot |
| `npx tsc --noEmit` | Type check only |

### Environment variables

Only one is needed, and only from phase 4: `OPENAQ_API_KEY`. It is read
server-side in a route handler and is never exposed to the browser. See
`.env.example`.

## Data integrity

Every value that reaches the UI carries a provenance classification, enforced
by the type system rather than by convention:

| Class | Meaning |
|---|---|
| `REAL` | Measured value retrieved from a public API |
| `SIMULATED` | Generated by this application — not a measurement |
| `STATIC` | Predefined configuration, or a value derived from it |
| `UNAVAILABLE` | No reliable source; the value is `null` |

Values are wrapped in `DataEnvelope<T>` (`src/types/data-envelope.ts`), which
carries the provenance, the source and its licence, the provider's measurement
timestamp, and the unit. Components render the badge from the envelope, so a
simulated or derived number cannot be displayed as a real-world measurement by
forgetting a caption.

Two deliberate consequences:

- **Building heights are `STATIC`, not `REAL`.** Only 1.4 % of Jakarta's OSM
  building footprints carry `building:levels` and 0.04 % carry `height`
  (measured — see `docs/api-validation.md`), so heights are derived and
  labelled as estimates.
- **AQI is computed only when the data supports it.** OpenAQ returns
  instantaneous values, while US EPA AQI for particulates requires NowCast
  averaging. Where enough hourly history is available the AQI is shown with its
  standard named; otherwise it is `UNAVAILABLE`. Single-station readings are
  never interpolated into a city-wide pollution field.

## Architecture

```
src/
  app/              routes, server-only API handlers, providers
  components/
    dashboard/      shell, view router, views
    navigation/     top bar, sidebar, clock, status
    panels/         information panel, analytics panel, layers, attribution
    ui/             primitives (provenance badge, stat tile, states)
  features/         per-domain services, hooks and types (city, weather, …)
  three/            3D scene, objects, materials, controls
  lib/              api clients, constants, geo helpers, utils
  stores/           Zustand UI state
  types/            shared contracts, including DataEnvelope
scripts/            build-time data generation (OSM snapshot)
docs/               API validation record
```

3D rendering lives under `src/three/` and is kept separate from dashboard UI.
Server data is owned by TanStack Query; Zustand holds UI state only, so a data
refresh never re-renders the 3D scene.

### Geometry is a build-time snapshot

OSM geometry is fetched once by `scripts/fetch-city-data.ts` and committed as
trimmed, pre-projected GeoJSON. Overpass's public instances are shared,
rate-limited and frequently overloaded — they were unreachable entirely during
this project's validation pass — so the deployed app never depends on Overpass
being up, and the published usage policy is respected.
